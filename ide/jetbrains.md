

# jetbrains IDE Integration Instructions

We are configuring an integration with the IDE. Follow the steps below to complete the setup.

| Step | Instructions                                                                    |               Screenshot                |
|:----:|---------------------------------------------------------------------------------|:---------------------------------------:|
|  1   | Open the **Settings**.                                                          | ![](../docs/images/ide-jetbrains-1.png) |
|  2   | Search for **Claude Code** plugin and install it if it is not already installed. |  ![](../docs/images/ide-jetbrains-2.png)   |
|  3   | Rename the **command executable**.                                              |  ![](../docs/images/ide-jetbrains-3.png)   |
|  4   | Start Claude from icon                                                          |  ![](../docs/images/ide-jetbrains-4.png)   |
|  5   | **Ready** to code                                                               |  ![](../docs/images/ide-jetbrains-5.png)   |
